

\# Shadow Slayer



Shadow Slayer is a 2D pixel-art action platformer developed with Unity 6.



\## Features

\- Three playable levels

\- Skeleton enemies and a final wizard boss

\- Sword combat and jumping

\- Crystal collection and health pickups

\- Moving platforms and dangerous obstacles

\- Mobile touchscreen controls

\- Main Menu, Settings, HUD, and Pause Menu

\- Music and sound effects



\## Controls

\- Virtual Joystick: Move

\- Jump: Jump between platforms

\- Attack: Sword attack

\- Pause: Pause the game

\- Resume: Continue playing

\- Restart: Restart the current level

\- Main Menu: Return to the menu



\## How to Run

1\. Install Unity Hub.

2\. Open this project with Unity 6 (6000.0.6f1).

3\. Open Assets/Scenes/MainMenu.unity.

4\. Press Play.
